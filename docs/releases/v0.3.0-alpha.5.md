# v0.3.0-alpha.5 — actual Rocket and native source-CPU flows

Package 0.3.0a5 adds the pinned RocketTile AXI32 instruction owner, source-built
RV64 M-mode software and a separate source-bound OpenSBI/Sv39/Linux boot profile.
Native IR v6 records actual CPU/source/ISA/privilege/reset ownership and explicit
halted QEMU/gem5 memory/IRQ contexts. Existing native ISS v3/v4/v5 remain supported.

The public 12/11-instance AI_SOC/AIZ_SOC source-CPU inputs exercise different maps,
reset entries and multiple Chipyard/OpenTitan IPs. Their five-workload native
flows use YAML and standard-bus XML, with the same selected ELF on both engines.
They are separate from the requested full 46/37-instance inventories and the
nine-component physical test chips.

Promotion requires actual CPU AXI/MMU/error/reset/IRQ/kernel tests, all three
legacy Rocket Linux maps on both engines, both native source-CPU five-workload
flows, zero gem5 ISS ownership, every previous mandatory native test, workflow
lint and clean minimal Debian. The exact candidate/JUnit/promotion receipt binds
qualification. A development version entry does not create an accepted tag.

Source-cache linking preserves the original executable entry; interrupted builds
remain unqualified. Parser metadata regeneration permits explicit pinned
QEMU/Zephyr/Linux reuse only with byte-checked original inputs/artifacts and new
provenance. Cold XSD initialization is serialized. Installed wheels include the
native RTL board script. Runtime assertions and raw instruction/AXI traces remain.

One hart, RV64IMAC, PA32, one aligned power-of-two RAM and atomic backing memory
bound this native CPU profile. The separate Rocket Linux fixture explicitly uses
32 MiB software RAM; native RTL Linux needs another generated BSP and is rejected.
BOOM, arbitrary CPU/bus/MMU adapters, full Earlgrey, generic DMA/coherence/time,
Yocto images and complete inventories remain open. RTL CPI/IPC is measured from
clock/retirement; silicon timing is uncalibrated. M1–M9 remain partial. Hosted CI,
release assets and a new rootless Podman SDK require separate observed evidence.
