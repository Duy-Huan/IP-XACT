# v0.3.0-alpha.3 — static address-decoder increment

Package 0.3.0a3 extends M1 with typed address spaces, bridge apertures,
local placements and checked physical lowering in canonical native IR v4.
The original v3 flat serialization remains compatible. Native lifecycle, both
engine lowerers and IR-derived software consume the checked projection.

Qualification requires actual translated Chipyard/OpenTitan MMIO/IRQ and all
four native RTOS/Zephyr BSPs on both engines and both original synthetic maps,
plus the complete prior mandatory gate. The immutable tag is created only after
the exact candidate passes local CI and main promotion; no result is inferred
from implementation or a planned version.

This static decoder subset does not qualify general standard IP-XACT bus XML,
AXI/TileLink transactions/timing, multiple CPU views, aliases, DMA/coherence or
asynchronous clock/reset bridges. Rocket/BOOM/full Earlgrey, Yocto, complete
inventories, cold all-engine/Podman/OCI and observed hosted acceptance stay open.
See docs/native-address-decoder.md and upgrade/milestones.yaml.
