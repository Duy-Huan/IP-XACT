# v0.3.0-alpha.4 — standard bus XML and hosted observation

Package 0.3.0a4 extends M1 with XSD-checked IEEE 1685-2022 bus definitions,
abstraction definitions, interfaces, address spaces/segments, subspace maps and
interconnections. Native IR v5 preserves the source graph and verifies its static
decoder projection. Supported fabric inputs export to validated standard XML.

AI_SOC/AIZ_SOC public XML examples target both engines and five native software
workloads. Qualification requires real source-IP MMIO/IRQ, identical equivalent
bare-metal ELF, complete prior mandatory local regression and main promotion.
The annotated immutable tag carries the exact qualification receipt and JUnit.

Hosted workflows publish actual job/source-release asset evidence through Git
notes. Query usp ci status with the exact commit/ref; an absent receipt remains
UNOBSERVED. Reports are repository-published, not independent API attestations.
Application source tags do not change the separately versioned SDK image.

The qualified bus is a static functional MMIO decoder tree, not AXI/TileLink or
a timing/interconnect model. General multi-initiator bus semantics, Rocket/BOOM,
full Earlgrey, Yocto and complete 46/37-instance implementations remain open.
M1-M9 are partial; see upgrade/milestones.yaml and docs/native-bus-xml.md.
