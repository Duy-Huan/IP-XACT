# v0.3.0-alpha.2 — sequential package and native software flow batch

Package: 0.3.0a2. This release is a scoped increment across M1/M2/M3/M4/M7.
The complete approved M1-M9 requirements and observed states live under upgrade/.
It does not close their broad remaining exits or final v0.3.0 acceptance.

New source packages pin model VLNV/license/source/build/driver contracts and
execute actual SystemC reset/MMIO/IRQ/error probes. `usp flow` persists a plan,
builds models and the selected engines, generates software and runs/verifies the
same canonical hardware/ELF on QEMU and gem5. A gem5-only path does not build QEMU.

The new AI_SOC/AIZ_SOC fixtures qualify native single-hart RV64 bare-metal,
FreeRTOS, Zephyr and explicit local LP64 ports of both public µC/OS kernels.
AI_SOC additionally qualifies native OpenSBI/Linux and two independent packaged
SystemC peripherals on a high physical map. These are qualification designs,
separate from the original full architectural inventories.

Plugin-enabled native QEMU records actual per-hart execution/data events and
configured analytical costs. These are uncalibrated estimates, distinct from
native gem5 cycles/CPI/IPC. Whole-guest intervals include boot and idle.

The owner requested sequential milestone implementation and one aggregate local
CI/CD gate after the complete batch is frozen. Promotion requires every prior
native gate plus the real package/flow/software/negative cases. The annotated tag
will contain the actual complete JUnit/checksum and source identity after that
gate, rather than predeclared test counts. Failed probes and explicit cache reuse
remain preserved with original identities.

Open exits include general IP-XACT buses/translations/reset domains,
heterogeneous/RTL CPU lowering, richer transaction/DMA/time/ROI/calibration,
general OS/IP drivers, a real Yocto image, complete inventories and matching full
RTL/physical designs. No new SDK image, cold all-engine rebuild, production ASIC
sign-off or observed hosted Actions success is asserted by this source tag.
